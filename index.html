Geometric model and assumptions

The auxiliary triangle extends the sightline behind the observation station to the ground plane. Its vertical component is the eye height E; its horizontal component is x = E / tan(theta).

The complete triangle has horizontal component B = D + x. The target height is H = B * tan(theta).

Algebraic reduction: height = eye height + distance × tan(angle).

Model limitations: nonhorizontal terrain, target inclination, step-length variability and angular error introduce height error. Elevation angles below 60 degrees are preferable. Displayed precision does not represent measurement accuracy.

Input parameters are retained in device-local browser storage.
